# arxn-n.github.io — Personal site of Arun Govind

Quantitative researcher & developer · Builder of [Akeyra](venture.html) and OperaFO · Dubai, UAE.

## Structure

```
index.html        About, featured venture, education, skills
experience.html   Full professional timeline
projects.html     Research projects with PDF reports
venture.html      Akeyra & OperaFO
catchup.html      Essays
css/styles.css    Design system (dark cosmic, violet + aurum)
js/site.js        Starfield canvas, scroll reveals, mobile nav
assets/           Images and project report PDFs
```

No build step, no dependencies — pure static HTML/CSS/JS. Serve locally with:

```
python3 -m http.server
```

Deployed via GitHub Pages from the `main` branch root.
